# esratjahan.github.io

Personal academic website of Esrat Jahan, served by GitHub Pages at https://esratjahan.github.io

- `index.html` — the whole site (HTML + CSS in one file, no build step).
- `photo.jpg` — add your photo here, then in `index.html` replace the `EJ` initials inside `<div class="photo">` with `<img src="photo.jpg" alt="Esrat Jahan">`.
- `.nojekyll` — tells GitHub Pages to serve the files as-is.

## Updating

Edit `index.html`, then:

```
git add .
git commit -m "Update site"
git push
```

The site refreshes within a minute or two.
